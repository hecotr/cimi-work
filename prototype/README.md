# Cimi Work 交互原型

按 `docs/Cimi-Work-PRD.md` 0.6 版制作的中文高保真原型，当前原型版本 0.2。采用 Hallmark Console 的 paper 浅色工作台方向，首页为“我的工作”。

## 本地运行

无需安装应用依赖，使用 Node.js 运行：

```powershell
node prototype/server.mjs
```

打开终端输出的 `http://127.0.0.1:4173`。静态应用位于 `dist/`，可直接部署。数据只保存在当前浏览器的 localStorage；页脚可重置演示数据。所有 Agent、成员、文件、回复、通知和执行过程均为演示，没有接入真实账号或 Agent。

## 建议体验顺序

1. 进入“执行资源”，新建 Agent，添加具体子 Agent 的职责、触发时机、输入范围、输出与前置依赖；保存草稿，再检查并发布。也可接入已有主体，外部管理的接入字段随后只读。
2. 新建通用 Team，选择具体 Agent、协调者、串行或按依赖并行的协作方式及汇总规则。Matrix 与 Harness 保留独立接入配置，Harness 示例支持 N1–N5 角色与显式验收策略。
3. 在资源详情分别配置空间使用权、配置编辑权和发布停用权。在项目“成员与资源”中启用多个主体，检查子 Agent、成员、工具和知识范围的依赖；默认主体可以不设。
4. 新建 Task，手动选择主体，或查看按目标与能力标签进行的本地匹配依据。没有就绪主体时仍保存目标为“未开始”，随后可以指派。
5. 发布资源新版本，观察已有 Task 继续使用旧绑定；通过“改派 / 采用新版本”填写原因、模拟停止确认后开启新 Run。选择“尚未收到停止确认”时，新执行不会启动。
6. 在任务概览查看实际分工、计划与派发、依赖和结果；邀请人时可以指定其工作是否是验收的必需条件。上下文页区分允许检索、实际使用、访问失败和用户附加材料，可演示资料授权待办。
7. 配置验收人、成果类型、报送对象与渠道，查看成果版本对应的规则检查和交付状态。空间或 Harness 可显式启用自动规则，Task 强制人工优先；外部未接入渠道保持“未发送”。
8. 继续体验初始故事：CW-1042 的口径确认、周报与验收修改；CW-1038 的 Harness 阶段与回退；CW-1035 的选择性成果发布。原私有 Task 保留，未选择的目标、资料和讨论不会进入项目。

## 实现边界

这是可点击的前端原型。任务推进、上下文查找记录、回退恢复、权限说明和自动验收均为本地规则模拟，不能据此推断真实多用户隔离、Agent 调度或云端状态同步已经实现。本地 Agent 入口显示为下一阶段能力。

默认人工验收。空间或 Harness 显式启用自动验收后，仅在演示成果产生时评估具体规则；检查、规则版本与成果版本关联。配置下一轮交付不会改写本次提交使用的验收人。选择的外部渠道未接入时不通过交付检查。

资源权限、连接就绪、委派、停止确认、资料读取和规则检查均在当前浏览器模拟。匹配采用可解释的本地标签规则，没有调用模型。模型、Skills、Tools/MCP 和 Runtime 字段保存引用，不连接真实能力。实际生产仍需 Runtime 适配、鉴权、业务检查器、真实通知和审计服务。

原型保留原来浏览器的任务、讨论和演示数据，首次加载时补充版本和绑定字段。历史来源与 Run 的初始版本按既有演示状态补齐，不视为从真实 Runtime 取回的运行记录。配置计划支持显式子 Agent 与固定 Team；无限制动态组队、任意 Harness 编排及真实本地接入继续后置。

在 320、375、768、1280、1440、1920 像素宽度检查首页、任务、创建、资源目录、资源详情和配置页，未发现页面级横向溢出。视觉检查发现手机资源标题被操作按钮挤窄，已改成标题与操作分行，并验证标题可读宽度。

Hallmark 渲染检查覆盖资源目录、新建配置、Team 编辑和资源详情，并在初轮检查任务详情：Floor 0、Reflex 0、未处理警告 0；F4 对中性控制的识别已核对并说明。视觉检查在本线程完成，使用原型快速流程。截图与原始检查结果生成在 `qa/`，不会随应用交付。

浏览器测试工具不随应用分发：

```powershell
npm install --prefix prototype/qa-deps --no-save puppeteer-core
node prototype/qa/verify.mjs
node prototype/qa/workbench.mjs
```

如 Chrome 不在默认路径，设置 `CHROME_PATH`；如预览端口不同，设置 `CIMI_PREVIEW_URL`。`qa/` 的测试脚本可重复运行，生成结果和截图会被 Git 忽略。

## 交付方式

按用户确认，仅保留本地原型，没有上传源码或发布在线预览。运行本地服务即可体验，停止服务后再次运行上述命令可恢复访问；浏览器中的演示记录仍会保留。
