# Cimi Work 产品介绍与蓝图

面向内部产品与技术团队，建议讲解 15 至 20 分钟。内容依据《Cimi Work PRD》v0.5 与项目蓝图；交互全部采用演示状态。

直接双击 `Cimi-Work-产品介绍与蓝图.html`。这一文件已内嵌样式、脚本与标题字体，可以离线打开、单独携带。需要修改时编辑 `index.html`、`data.js` 与 `styles.css`，然后执行：

```powershell
node briefing/build.mjs
```

## 参考页如何制作

参考 `authz-atlas` 的四个文件可以看出，它是一个原生浏览器应用，没有框架或后端依赖：

| 文件 | 职责 | 参考页中的做法 |
| --- | --- | --- |
| `index.html` | 叙事骨架与无脚本正文 | 章节、标题、说明、目录容器与交互区域 |
| `styles.css` | 统一视觉系统 | CSS 变量、浅灰网格、宋体标题、固定左栏、语义色、响应式与明暗主题 |
| `data.js` | 可解释的领域模型 | 节点、边、权限、场景、决策、执行点和验证数据 |
| `app.js` | 将模型变成可操作图谱 | 创建 DOM 与 SVG、计算状态、高亮路径、逐步导览、抽屉说明和键盘操作 |

制作顺序是：先整理讲解主线，再给每个章节选择最能说明问题的图形或交互；把概念、关联和规则写成数据；让渲染函数读取数据；最后统一视觉、响应式与操作反馈。交互承担解释职责，例如选择一个场景后高亮路径，或者改变条件后展示判断结果。

参考页使用 CSS 自定义属性集中管理配色和字体，浅灰制图网格提供图谱语境。左栏目录与正文滚动关联，沉浸模式收起目录，键盘导览支持讲解时连续推进。外部 Google Fonts 为参考页提供字体；本版把同款开源 Noto Serif SC 的标题字形子集打包到本地，离线时也能保持相近的字重与气质。

本版沿用它的目录、网格、宋体和语义色，但重新编写 Cimi Work 内容与交互，没有复制权限方案的领域规则。正文、数据和脚本仍然分开维护；`build.mjs` 生成可独立分发的单文件 HTML。

## 建议讲解路径

| 章节 | 时间 | 演示动作与讲解重点 |
| --- | --- | --- |
| 00 让工作持续推进 | 1 分钟 | 切换三个 Run，Task 的共同事实保留 |
| 01 Task 协作全景 | 3 分钟 | 按七步导览走一遍；讨论时点击节点 |
| 02 空间与共同事实 | 2 分钟 | 切换空间、选择发布材料、点开 Run 等对象 |
| 03 从目标走到交付 | 3 分钟 | 停在 Run 成功但 Task 待验收，再走到验收 |
| 04 四类执行机制 | 2 分钟 | 区分单 Agent、通用 Team、Matrix 与 Harness |
| 05 专业流程与回退 | 2 分钟 | 演示 N2 回到 N1，保留历史并重新评估证据 |
| 06 产品与执行边界 | 2 分钟 | 解释四层职责，切换明确委托、反馈与候选 |
| 07 分阶段落地 | 2 分钟 | 首版云端闭环、下一阶段验证、后续增强 |
| 08 验收与待对齐项 | 1 分钟 | 用讨论清单对齐下一步 |

按 `N` 显示讲解备注，按 `F` 进入或退出沉浸模式。`J` / `K` 切换章节；全景图与交付故事中的左右键切换步骤。表页签支持左右键、Home 与 End。手机使用“章节目录”按钮。打印讲义会展开讲解备注并隐藏导航。

## 内容边界

页面呈现产品设计和实施建议，不声明已经完成真实 Agent、通知、Harness 或本地执行接入。分析故事与阶段回退均有明显演示标识。当前首版优先真实云端交付，本地 Agent 协作在下一阶段验证，路线不使用未经确认的日期或完成率。

主要来源：PRD 第 1 至 5 节（定位、空间与协作）、第 6 至 7 节（故事与职责）、第 8 至 9 节（实施与验收）、第 11 至 12 节（待评审项与演示边界）。历史蓝图中的旧产品名在讲解页统一为 Cimi Work。

## 维护与验证

`tokens.css` 管理颜色、字体和尺度，`base.css` 是基础可访问性样式，`styles.css` 管理本页面布局，`data.js` 保存内容与流程状态，`app.js` 处理交互。原型目录 `prototype/` 不属于本次修改。

`verify.mjs` 使用 Puppeteer Core 和本机 Chrome 进行浏览器检查；用环境变量 `HALLMARK_PUPPETEER` 指向已安装该依赖的目录，`CHROME_PATH` 指向浏览器。验证覆盖主要交互、键盘导览、320 至 1920 像素布局、明暗主题、打印、禁用脚本阅读和单文件断网打开。检查报告与截图写入未跟踪的 `.qa/`。

字体：Noto Serif SC，SIL Open Font License 1.1，许可证见 `fonts/OFL.txt`。标题使用官方字体服务返回的未改动子集，新增未覆盖字形会回退到系统宋体；大幅修改标题时应更新字体子集。
